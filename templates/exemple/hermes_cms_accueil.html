Hermes CMS

Créez des sites vitrines élégants et responsives : menus, pages, galeries, formulaires et contenus riches — sans dépendre d’un éditeur de page propriétaire. Hermes s’appuie sur Symfony 8, Bootstrap 5 et les standards du web moderne.

Découvrir les fonctionnalités Code source (MIT)

Pensé pour les vitrines

Portfolios, carrousels, cartes, pages institutionnelles, contact et pied de page : tout est structuré en menus → pages → sections → posts, avec activation fine de chaque bloc.

Identité visuelle maîtrisée

Couleurs, largeurs, fonds, typographies (polices web @fontsource), navbar (base, latérale, pleine largeur), footer global et liens du contenu : l’administration centralise l’apparence du site.

Stack actuelle, sans Node obligatoire

Asset Mapper et importmap pour Bootstrap, CKEditor 5, Uppy, Stimulus et Symfony UX — déploiement simple, évolutif, aligné sur PHP 8.4+.

Ce que vous pouvez faire dès aujourd’hui

  • Gabarits « liste » — folios (plusieurs variantes), carrousels, cartes avec téléchargement, galeries modales, colonnes et filtres image configurables par section.
  • Contenu libre — édition riche avec CKEditor 5 (HTML, médias intégrés au site).
  • Catalogue API Hermes — importez des modèles prêts à l’emploi depuis api.hermes-cms.org (mentions légales, blocs libres, pages types…).
  • Menus hiérarchiques — pages et sous-pages, ordre, activation / désactivation, programmation possible, copie et déplacement de contenu.
  • Multilingue — duplication d’une locale vers une autre (menus, sections, posts, footer) pour lancer rapidement une version EN / FR.
  • Formulaires intégrés — contact, newsletter, livre d’or (styles et textes configurables).
  • Pied de page dédié — sections footer globales + plan du site en modale.
  • Médias — arborescence admin, upload Uppy, redimensionnement Liip Imagine, import en masse sur les listes.

L’API Hermes, votre bibliothèque de modèles

Le catalogue centralise des gabarits HTML maintenus pour Hermes : pages légales, blocs de présentation, structures Bootstrap testées. Dans l’administration, sélectionnez un modèle, prévisualisez, injectez le contenu dans une section libre — sans repartir de zéro à chaque site.

Exemples fournis côté API : modèles mentions-legales, confidentialite, cgu-cgv pour constituer rapidement le socle juridique d’un site vitrine.

Pourquoi choisir Hermes pour votre prochain site vitrine ?

Responsive natif
Gabarits Bootstrap 5, largeurs de colonnes réglables (grille 12).

Open source MIT

Modulaire
Gabarits liste, libre, formulaires et footer : composez chaque page à votre rythme.

Prochainement

  • Parcours guidé « premier site » et assistant de choix de gabarit API

  • Prévisualisation live des modèles API avant import dans une section
