• CMS open source · sites vitrines

    HERMES CMS

    Créez des sites vitrines élégants et responsives : menus, pages, galeries, formulaires et contenus riches — sans éditeur de page propriétaire. Basé sur Symfony 8, Bootstrap 5 et les standards du web moderne.

    Code source (MIT) Catalogue API

  • VITRINES

    Portfolios, carrousels, cartes, pages institutionnelles, contact et pied de page : tout est structuré en menus → pages → sections → posts, avec activation fine de chaque bloc.

  • IDENTITÉ

    Couleurs, largeurs, fonds, typographies @fontsource, navbar, footer global et liens du contenu : l’administration centralise l’apparence du site.

  • STACK MODERNE

    Asset Mapper et importmap pour Bootstrap, CKEditor 5, Uppy, Stimulus et Symfony UX — déploiement simple, sans Node obligatoire, aligné sur PHP 8.4+.

  • Fonctionnalités

    AU QUOTIDIEN

    • Gabarits liste — folios, carrousels, cartes, galeries modales.
    • Contenu libre — édition riche CKEditor 5.
    • Multilingue — duplication FR / EN en un clic.
    • Médias — arborescence admin, upload Uppy, Liip Imagine.

  • API HERMES

    Importez des modèles prêts à l’emploi depuis api.hermes-cms.org : mentions légales, blocs libres, pages types — sans repartir de zéro.

  • Pourquoi Hermes

    OPEN SOURCE

    • Rapide — interface admin claire, logique pages / sections.
    • Responsive — Bootstrap 5, grille 12 colonnes.
    • MIT — hébergez où vous voulez, adaptez le code.
    • Modulaire — liste, libre, formulaires, footer.
